
# Thinking in React (2026)

This is my implementation of a review lesson on React, as it was on March 26th, 2026: https://react.dev/learn/thinking-in-react

The code here is my unique implementation that uses none of the code given by the page above. It 
is a Vite project that uses features and application structure not detailed in the review lesson, 
as additional exercises for creating live applications.

This includes the use of TypeScript, asynchronous data retrieval, separation of 
components/types/utilities/etc into a file structure, styles per component, and more.

This is part of my re-introduction to React in 2026.

Run this application using `npm run dev` and going to http://localhost:5173/
